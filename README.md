# Stone Paper Scissors

A simple, lightweight browser game built with HTML, CSS, and JavaScript. Pick rock, paper, or scissors and compete against the computer in best-of series rounds.

## 🚀 Live Demo
Open `index.html` in your browser (double click or serve via local web server).

## 🧩 Project Structure
- `index.html` - core UI elements and buttons
- `style.css` - responsive styling and animation
- `app.js` - game logic, score tracking, and UI updates
- `images/` - assets for rock / paper / scissors icons

## 🎮 How to Play
1. Open `index.html` in browser
2. Click one of the choices: Rock, Paper, or Scissors
3. Computer randomly picks a choice
4. Result shown instantly (win/lose/draw)
5. Scores update on every round
6. Reset game using the Reset button (if implemented)

## ✨ Features
- Clean UI with touch-friendly controls
- Randomized computer choice
- Round result and cumulative scoring
- Accessible to keyboard and mouse (basic)
- Easy to extend (add sounds, animations, multiplayer)

## 🛠️ Optional Enhancements
